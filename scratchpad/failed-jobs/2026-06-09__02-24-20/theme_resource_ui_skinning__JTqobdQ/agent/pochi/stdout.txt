# Runtime Theme Resource with Type Variations and Light/Dark Switching ## Background Godot 4's GUI skinning system uses the `Theme` resource to drive how every `Control` node is rendered. A theme stores typed items (colors, fonts, font sizes, constants, icons, styleboxes), organized by *theme types* (e.g. `Button`, `Label`, `Panel`). On top of the built-in types, themes can declare **type variations**: named theme types that inherit from a base built-in type and override a subset of items. A `Control` opts into a variation by setting `theme_type_variation` (or by calling `set_theme_type_variation()`), and any unmatched item falls back to the base type. In this task you will build a small Godot 4 project that constructs a `Theme` resource entirely at runtime (not via the inspector and not loaded from a `.tres`), wires it to a root `Control`, exposes a public API to swap between a "light" and a "dark" variant at runtime, and provides two custom button type variations: `PrimaryButton` and `DangerButton`.
