## Files created

### `scripts/Minimap.gd`
Extends `SubViewportContainer`. Declares:
```gdscript
@export var world_root: NodePath
@export var player_path: NodePath
signal poi_added(poi_index: int)
func get_marker_for_poi(index: int) -> Node2D
```

**Runtime behaviour**
- `_ready` → locates the `SubViewport` child and its `Camera2D`, then defers `_init_tracking`.
- `_init_tracking` → resolves `player_path`, queries `get_nodes_in_group("poi")`, creates one `Node2D` marker per POI, and emits `poi_added(i)` exactly once per POI.
- `_process` → syncs the Camera2D's `global_position` and the player marker's `position` to `_player.global_position` every frame (satisfies the `(123, -45)` position check after one frame). POI markers are also refreshed each frame so `get_marker_for_poi(0).position` equals the first POI's world position.

### `scenes/Minimap.tscn`
```
SubViewportContainer  [script: res://scripts/Minimap.gd]
└─ SubViewport        size=Vector2i(256,256)  transparent_bg=true
   └─ Camera2D        zoom=Vector2(0.1,0.1)   enabled=true
```
The `Camera2D` is the only camera in the `SubViewport`, so Godot automatically makes it the current camera for that viewport. `enabled=true` is also set explicitly.
