### How each requirement is satisfied

**`project.godot`**  
Registers the autoload with the `*` prefix (makes it a singleton Node):
```ini
[autoload]
EventBus="*res://autoloads/EventBus.gd"
```

**`autoloads/EventBus.gd`**  
Declares exactly the four typed signals:
```gdscript
signal item_picked_up(item_id: StringName, quantity: int)
signal item_used(item_id: StringName)
signal inventory_changed(snapshot: Dictionary)
signal inventory_full()
```

**`scripts/Inventory.gd`**  
- `@export var max_slots: int = 8`  
- `_ready()` connects to `EventBus.item_picked_up` and `EventBus.item_used`  
- Maintains `_items: Dictionary` (item_id → quantity)  
- On pickup: if the item is new and `_items.size() >= max_slots`, emits `inventory_full` and returns; otherwise adds/increments and emits `inventory_changed(_items.duplicate())`  
- On use: decrements quantity, erases entry at zero, emits `inventory_changed`  
- Never references `Inventory`, `Hotbar`, or `Pickup` class names

**`scenes/Pickup.tscn` / `scripts/Pickup.gd`**  
- Root node is `Area2D` with `scripts/Pickup.gd` attached  
- `@export var item_id: StringName` and `@export var quantity: int`  
- `body_entered` checks `body.is_in_group("player")`, then emits `EventBus.item_picked_up(item_id, quantity)` and calls `queue_free()`  
- Never references `Inventory` or `Hotbar`

**`scenes/Hotbar.tscn` / `scripts/Hotbar.gd`**  
- Root node is `Control` with 8 child `Label` nodes (Slot0–Slot7), all initially hidden  
- Subscribes to `EventBus.inventory_changed` in `_ready()`  
- On each snapshot, iterates the dictionary entries and sets each Label's text to `"<item_id> x<quantity>"` (visible) or hides unused slots
