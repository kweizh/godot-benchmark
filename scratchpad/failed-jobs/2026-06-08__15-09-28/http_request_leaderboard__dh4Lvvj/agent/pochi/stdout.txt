**Note on `class_name` + autoload:** Godot 4.3 raises a parse error if an autoload singleton is registered with the `*` (singleton) prefix *and* the script also declares `class_name` with the same identifier (name collision). The autoload is registered **without** the `*` prefix, which means it is still accessible globally as `LeaderboardClient` (the autoload node is added to the root with that name, which is the normal way to use autoloads in GDScript), while the `class_name` declaration remains valid for static typing.
