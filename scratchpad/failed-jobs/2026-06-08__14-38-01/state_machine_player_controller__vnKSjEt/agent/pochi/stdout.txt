### Project Overview

### Implemented Files
1. **`scripts/states/State.gd`**: The base class for all states, extending `Node`. It defines the template interface for entering, exiting, processing, and handling physics updates.
2. **`scripts/StateMachine.gd`**: The State Machine controller that manages state transitions, delegates process/physics ticks, and emits the `state_changed(prev: StringName, next: StringName)` signal.
3. **`scripts/states/IdleState.gd`**: Handles the player in a stationary/idle state, transitioning to `Run` on horizontal input, `Jump` on `ui_accept`, `Attack` on `attack`, and `Fall` if the player is not on the floor.
4. **`scripts/states/RunState.gd`**: Handles horizontal movement and transitions back to `Idle` when movement input stops, as well as `Jump`, `Attack`, and `Fall` transitions.
5. **`scripts/states/JumpState.gd`**: Applies upward velocity and transitions to `Fall` once the vertical velocity is downward (`velocity.y > 0`).
6. **`scripts/states/FallState.gd`**: Handles gravity and transitions back to `Idle` once the player lands on the floor (`is_on_floor()`).
7. **`scripts/states/AttackState.gd`**: Locks horizontal movement and transitions back to `Idle` after exactly `0.4` seconds (satisfying the 0.3 s to 0.6 s window).
8. **`scripts/Player.gd`**: Extends `CharacterBody2D` and defines standard movement constants (`speed`, `jump_velocity`, and `gravity`).
9. **`scenes/Player.tscn`**: A scene with a `CharacterBody2D` root containing a `CollisionShape2D` and a `StateMachine` child, which in turn has five children named exactly `Idle`, `Run`, `Jump`, `Fall`, and `Attack`.
10. **`project.godot`**: Configured with `res://scenes/Player.tscn` as the main scene and the custom `attack` input action bound to the `J` key (keycode 74).
