### 1. `shaders/water_distortion.gdshader`
This `canvas_item` shader performs a water-like UV distortion of the screen behind the node. It declares all the requested uniforms with proper ranges and defaults, and samples the `screen_texture` at `SCREEN_UV` offset by a `sin`/`cos` wave derived from `TIME` and `UV`. It then mixes the sampled color with `tint_color` using `tint_color.a` as the mix factor.

```gdshader
shader_type canvas_item;

uniform float time_scale : hint_range(0.0, 4.0) = 1.0;
uniform float wave_amplitude : hint_range(0.0, 0.1) = 0.02;
uniform float wave_frequency : hint_range(0.1, 50.0) = 10.0;
uniform vec4 tint_color : source_color = vec4(0.4, 0.7, 1.0, 0.5);
uniform sampler2D screen_texture : hint_screen_texture, repeat_disable, filter_linear;

void fragment() {
    vec2 wave_uv_offset;
    wave_uv_offset.x = sin(TIME * time_scale + UV.y * wave_frequency);
    wave_uv_offset.y = cos(TIME * time_scale + UV.x * wave_frequency);
    vec2 distorted_uv = SCREEN_UV + wave_uv_offset * wave_amplitude;
    vec4 sampled_color = texture(screen_texture, distorted_uv);
    COLOR = mix(sampled_color, tint_color, tint_color.a);
}
```

### 2. `scenes/Water.gd` (Attached GDScript Controller)
This controller exports the four configuration variables and, in its `_process(delta)` loop, propagates them to the shader material via `set_shader_parameter`, ensuring the shader is kept in sync with the exported properties in real-time.

```gdscript
extends ColorRect

@export var time_scale: float = 1.0
@export var wave_amplitude: float = 0.02
@export var wave_frequency: float = 10.0
@export var tint_color: Color = Color(0.4, 0.7, 1.0, 0.5)

func _process(_delta: float) -> void:
	if material is ShaderMaterial:
		material.set_shader_parameter("time_scale", time_scale)
		material.set_shader_parameter("wave_amplitude", wave_amplitude)
		material.set_shader_parameter("wave_frequency", wave_frequency)
		material.set_shader_parameter("tint_color", tint_color)
```
