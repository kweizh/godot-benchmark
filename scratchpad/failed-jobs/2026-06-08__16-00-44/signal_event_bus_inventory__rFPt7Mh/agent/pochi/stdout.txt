Godot 4 decoupled inventory project created at `/home/user/myproject` with the following structure:

**`project.godot`** — Registers `EventBus` as an autoload singleton pointing to `res://autoloads/EventBus.gd`.

**`autoloads/EventBus.gd`** — Declares exactly four signals:
- `item_picked_up(item_id: StringName, quantity: int)`
- `item_used(item_id: StringName)`
- `inventory_changed(snapshot: Dictionary)`
- `inventory_full()`

**`scripts/Inventory.gd`** — Extends `Node` with `@export var max_slots: int = 8`. Maintains a `Dictionary` mapping `item_id → quantity`. Connects to `EventBus.item_picked_up` and `EventBus.item_used` in `_ready()`. On pickup: if the item is new and `max_slots` distinct entries already exist, emits `inventory_full` and refuses the add; otherwise updates the dictionary and emits `inventory_changed(snapshot)`. On use: decrements quantity, removes the entry at zero, and emits `inventory_changed(snapshot)`.

**`scenes/Pickup.gd` / `Pickup.tscn`** — An `Area2D` with `@export var item_id: StringName` and `@export var quantity: int = 1`. Connects to its own `body_entered` signal; when a body in group `"player"` enters, emits `EventBus.item_picked_up(item_id, quantity)` and calls `queue_free()`.

**`scenes/Hotbar.gd` / `Hotbar.tscn`** — A `Control` with `@export var max_slots: int = 8`. Creates `max_slots` child `Label` nodes in `_ready()`, subscribes to `EventBus.inventory_changed`, and renders each populated slot as `"<item_id> x<quantity>"` while hiding empty slots.

**`scenes/Main.tscn`** — Composites `Inventory` and `Hotbar` nodes under a `Node2D` root.

All interactions flow exclusively through `EventBus` — neither `Inventory.gd` nor the Pickup script reference the `Inventory` or `Hotbar` class names.
